## demo.sh

```bash frame="terminal"
./scripts/demo.sh up-shared
./scripts/demo.sh up-consumer syd|akl
./scripts/demo.sh allowlist
./scripts/demo.sh publish [local-file]
./scripts/demo.sh prove syd|akl
./scripts/demo.sh status
./scripts/demo.sh down
```

## Environment

| Name | Required for | Notes |
| ---- | ------------ | ----- |
| `AWS_PROFILE` | all | e.g. `sandbox` |
| `NAME_PREFIX` | optional | Default `ps3a` |
| `LAB_SUFFIX` | optional | Default timestamp on first `up-shared` |

`up-consumer syd` builds a lab VPC in `ap-southeast-2`. `up-consumer akl` does
the same in `ap-southeast-6`. Run both before allowlist and prove.

State file: `.lab-state.json` (gitignored).
